# D-MATH COSMOGENESIS HISTORIA 1.0.0

Created by Yucong Duan (段玉聪).

## 宇宙发生数学与《宇宙的数学新史》配套系统

本系统不预设对象、数、空间、时间、物质、意识或真值为宇宙原语。内核从匿名续生关系、替换余量与未来同效商开始，生成对象、规律、时间箭头、运输几何、信息细化、DIKWP开放角色与六类证明凭证。

核心顺序：

```text
匿名痕迹 → 续生 → 替换余量 → 未来同效商 → 对象 → 规律 → 时空图册 → 生命/意识投影
```

系统包含：

- 有限匿名续生世界分析器；
- 未来同效商与最短区别续生；
- 规律同余检查；
- 时间箭头、区别擦除与运输成本；
- 路径余量与语义曲率；
- D/I/K/W/P角色投影；
- 发生、局部必然、世界接触、相互理解、非坍塌、形式投影六类凭证；
- 12项可执行元定理；
- 离线交互驾驶舱；
- 《宇宙的数学新史》完整书稿。

### 快速运行

```bash
python -m pip install dist/dmath_cosmogenesis_historia-1.0.0-py3-none-any.whl
cosmohistoria conformance --out outputs/conformance.json
cosmohistoria demo --out outputs/run
cosmohistoria analyze examples/latent_split.json --out outputs/latent.json
cosmohistoria verify outputs/run
```

打开 `outputs/run/dashboard.html`。

### 证据边界

本系统证明的是有限声明世界中的算法与元定理。物质、生命、意识、量子样和引力样解释属于可证伪投影，不构成现实宇宙已经接受该本体的经验结论。
